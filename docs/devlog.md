## Что сделали и что получилось

Через MCP-инструменты (`issue_write`, `list_issues`, `get_label`) создано 11
issues — весь маршрут Track B в порядке таблицы (EXT-100 → BEVN-205), по

## Где вмешался руками

- Label `optional` в репозитории завёл вручную сам — подходящего write-
  инструмента для создания меток в наборе GitHub MCP сервера нет (есть только
  `get_label` на чтение); агенту прямо запретил подменять это CLI/curl.
- Список из 11 issues (заголовки + источник body) утверждал по таблице до
  того, как агент начал что-либо создавать — план проверялся построчно.
